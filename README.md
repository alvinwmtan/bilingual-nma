# Measuring bilingual vocabulary: A systematic review and meta-analysis

This repository contains code for reproducing the manuscript "Measuring bilingual vocabulary: A systematic review and meta-analysis". 

To reproduce the outputs, run/render the Quarto files `0x-*.qmd` in order, which will write outputs to the `outputs` directory. Note that the data are by default pulled from the Google Sheets where we were doing data extraction; a cached version in the `data/raw_data` directory is also available.

To reproduce the manuscript, after having generated all the outputs, render the Quarto file `writing/writing.qmd`.
